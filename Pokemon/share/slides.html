Como funciona uma requisição HTTP

Origem Aplicação cliente
1. Cliente envia a requisição GET /api/v2/pokemon/pikachu
2. Servidor recebe, processa e monta a resposta
3. Servidor devolve a resposta 200 OK + JSON
Destino Servidor da API

A requisição parte do cliente; a resposta retorna somente após o processamento.

Métodos HTTP mais comuns

MétodoObjetivoExemplo
GETConsultar um recurso.GET /pokemons/25
POSTCriar um novo recurso.POST /pokemons
PUTSubstituir um recurso.PUT /pokemons/25
PATCHAlterar parte de um recurso.PATCH /pokemons/25
DELETERemover um recurso.DELETE /pokemons/25

Como funciona o JSON

Documento
{
  "nome": "pikachu",
  "id": 25,
  "ativo": true,
  "tipos": [
    "electric"
  ]
}
Estrutura
  • Objetos são delimitados por { }.
  • Listas são delimitadas por [ ].
  • Propriedades usam pares nome: valor.
  • Textos usam aspas duplas.
  • Valores podem ser texto, número, booleano, nulo, objeto ou lista.
Desserializar transforma JSON em objetos C#; serializar transforma objetos C# em JSON.

Arquivo de entrada

{
  "nomes": [
    "pikachu",
    "bulbasaur",
    "charizard",
    "squirtle",
    "eevee"
  ]
}

O arquivo deve ser salvo como pokemons.json na pasta de execução do projeto.

Leitura e desserialização

using System.Text.Json;

var options = new JsonSerializerOptions(
    JsonSerializerDefaults.Web);

string json = await File.ReadAllTextAsync(
    "pokemons.json");

PokemonInput entrada =
    JsonSerializer.Deserialize<PokemonInput>(
        json, options)
    ?? throw new JsonException(
        "Arquivo de entrada inválido.");

A falha de leitura ou de formato deve ser apresentada; não use valores silenciosos como substituição.

Consulta com HttpClient

using System.Net.Http.Json;

using var http = new HttpClient
{
    BaseAddress = new Uri(
        "https://pokeapi.co/api/v2/")
};

string nome = "pikachu";

PokemonApiResponse? resposta =
    await http.GetFromJsonAsync<PokemonApiResponse>(
        $"pokemon/{nome}");

GetFromJsonAsync realiza a requisição e desserializa o corpo da resposta.

Modelos com responsabilidades diferentes

Resposta externa
public sealed class PokemonApiResponse
{
    public int Id { get; init; }
    public string Name { get; init; } = "";
    public int Height { get; init; }
    public int Weight { get; init; }
    public PokemonSprites Sprites { get; init; } = new();
    public List<PokemonTypeSlot> Types { get; init; } = [];
}
Objeto da aplicação
public sealed record PokemonDetalhado(
    int Id,
    string Nome,
    double AlturaMetros,
    double PesoQuilos,
    List<string> Tipos,
    string? Imagem);
O Data Transfer Object (DTO) externo acompanha o contrato da API; o objeto interno acompanha a necessidade da aplicação.
